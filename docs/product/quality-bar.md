# 품질 기준

전문 비평가가 세계 최고 수준의 소비자 앱과 나란히 놓고 평가한다고 가정합니다. 아래 항목으로 판단하며, 각 항목은 실제 화면이나 테스트 결과를 근거로 삼습니다.

## 치명 기준

하나라도 어기면 출시할 수 없습니다.

- 양측 동의 없이 연결이나 연락처 교환이 열립니다. 자동 연결은 양측의 요청·수락 동작 또는 AUTO 설정을 통한 사전 동의가 있어야 합니다.
- 60점 미만이거나 공개하지 않은 점수, 상대의 주행 이력·지원/통과 횟수가 다른 사람에게 보입니다.
- 주행 중 연결 모드나 조건을 편집할 수 있거나, 집 보호 중·차단한 상대에게 자동 요청·수락이 실행됩니다.
- 자동 연결이 통화 종료 뒤 10분 대기나 같은 날 같은 상대 재시도 금지를 무시합니다.
- 끝난 연결이 늦은 응답이나 재접속으로 되살아납니다.
- 다른 사람의 연결, 연락처, 기록을 읽거나 바꿀 수 있습니다.
- 상호 애프터 수락 전에 상대 ID가 보이거나, 차단·관계 종료·계정 삭제 뒤 교환 ID가 API·화면·과거 명령 결과에 남습니다.
- 주행 제한·상태 불명에서 연락처 ID나 QR이 보이거나 저장한 개인 ID가 공개 프로필·후보·요청·기록·알림·로그에 나타납니다.
- 정확한 위치, 궤적, 차량 식별 정보가 상대나 서버 응답, 로그에 나타납니다.
- 주행 중 새 사람 탐색·수동 발신 요청·일반 요청 수락·입력·편집이 가능합니다. RESTRICTED의 예외는 RING/AUTO의 전용 수신 화면 받기/거절과 사전 AUTO 동의·조건·보호 규칙을 모두 통과한 자동 요청·수락뿐입니다. UNKNOWN에서는 이 예외도 없습니다.
- 현재 활성 연결의 두 참가자 밖으로 음성이 전달되거나, 음성이 녹음·저장·로그에 남습니다.
- 활성 상태이며 음소거가 아닌 허가된 서버 통화 밖에서 마이크가 열립니다. SOLO 또는 SERVER_DEMO의 데모 상대에게 마이크나 음성 WebSocket이 열립니다.
- 연결 종료·집 보호 후 오디오나 통화 서비스가 계속 실행됩니다. 데모 음성이 포커스 없이 재생되거나 종료 뒤 이어집니다. 주행 중 권한 창이 열립니다.
- 실제 소리 시작을 확인하지 않은 SDK 콜백만으로 상대가 말하는 중이라고 표시합니다.
- 속도나 공격적 운전을 칭찬합니다.
- 데이터 출처로 사용자를 오해하게 합니다. SOLO는 서버 주소가 없으면 첫 프로필 만들기에서, 서버 주소가 있으면 모드 선택에서 가상 상대임을 알리고 내 시그니처 근거에서 출처를 확인할 수 있어야 합니다. 서버 모드는 실제 사람과 섞이는 가상 상대와 합성 데이터의 표시를 유지해야 합니다.
- 앱이 충돌하거나, 빈 화면에 갇히거나, 뒤로 갈 수 없습니다.
- 저장소나 화면에 개발자 실명, 개인 계정, 비밀 값이 있습니다.

## 경험 기준

| 항목 | 통과 조건 |
|---|---|
| 첫인상 | 첫 화면 3초 안에 앱의 정체와 특별함이 느껴집니다 |
| 차량 특화 | 시그니처가 데이터 표가 아니라 사람의 매력으로 읽힙니다. 차 밖에서는 불가능한 경험입니다 |
| 시각 완성도 | 시안의 입체감, 광택, 깊이, 위계가 그대로 구현됩니다. 기본 Material 느낌이 없습니다 |
| 일관성 | 간격, 곡률, 그림자, 글자, 색이 토큰에서만 나옵니다 |
| 움직임 | 연결, 종료, 매듭 연출이 상태 변화를 설명합니다. 주행 중에는 조용합니다 |
| 상태 | 불러오기, 빈 화면, 오류, 만료, 주행 제한이 모두 디자인되어 있습니다. 기술 오류 문구가 없습니다 |
| 문구 | 사람이 쓴 것처럼 자연스럽고, 다음 행동이 분명합니다 |
| 신뢰 | 무엇을 읽고 무엇이 공유되는지 언제든 확인하고 끌 수 있습니다 |
| 반응 | 터치 후 100ms 안에 반응이 보입니다. 스크롤과 연출이 끊기지 않습니다 |
| 접근성 | 차량 터치 크기, 대비, 스크린 리더 설명을 지킵니다 |

## 엔지니어링 기준

- `python3 scripts/dev.py verify`가 깨끗한 환경에서 통과합니다.
- 금지된 모듈 의존성은 빌드에서 실패합니다.
- 상태 전이, 시그니처 계산, 궁합은 결정적 단위 테스트가 있습니다.
- 서버는 경합, 중복, 역순, 권한 시나리오 테스트가 있습니다. 통화 종료 명령부터 양쪽 소켓 폐쇄까지 300ms 이내인지 확인하며, 프레임 중계·재생 전달 경로에서 엔진 상태를 매번 조회하지 않습니다. 순간 버스트와 지속 과부하를 구분해 테스트합니다.
- 모든 화면과 주요 상태에 스크린샷 테스트가 있습니다.
- Pleos 에뮬레이터에서 실제 차량 신호로 주행 → 시그니처 반영 → 주행 잠금을 검증합니다.

## 정직성

세계 순위는 측정할 수 없습니다. 완성 보고에는 검증한 사실과 비평가 평가, 남은 한계를 구분해 적고, 순위를 달성했다고 주장하지 않습니다.
