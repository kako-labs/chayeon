# 제품 결정 기록

제품 담당자가 내린 방향 결정과 그 이유를 시간순으로 남깁니다. 결정의 세부 규칙은 [경험 명세](experience-spec.md), [드라이브 시그니처](drive-signature.md), [품질 기준](quality-bar.md)에 반영되어 있습니다.

## 차연을 만드는 이유

운전 스타일은 사람마다 천차만별이고, 많은 사람이 그 차이로 상대를 고릅니다. "난폭하게 운전하는 사람은 싫다", "차분하게 운전하는 사람이 좋다"처럼 운전 습관이 이상형을 가르기도 합니다. 차는 오래 머무는 공간이라 그 안에서의 모습에 성격이 드러납니다.

그래서 차연에서는 운전 정보가 곧 프로필입니다. 상대는 이 프로필을 자유롭게 보고, 매칭 조건으로 쓰고, 통화 중에도 간략한 값을 확인합니다. 화면이나 기능을 정할 때 이 프로필을 약하게 다루지 않습니다.

## 2026-11-13 결정

| 결정 | 이유 | 반영 |
|---|---|---|
| 연결되면 바로 음성 통화를 시작하고, 주행 중에도 통화를 이어 간다. 통화를 끊으면 연결도 끝난다 | 운전 중에는 글을 쓸 수 없다. 주행 중에 이야기하지 못하면 앱을 쓸 이유가 약하다 | 서버가 두 참여자 사이에만 음성을 실시간으로 전달하고 녹음·저장하지 않는다 |
| 주행 중에는 이미 이어진 상대와의 통화만 유지한다. 새 사람을 찾고 요청하는 일은 주차 중에 한다 | 운전 안전 | 주행 중 조작은 음소거와 통화 끊기뿐이다 |
| `주행 중 연결` 설정을 둔다: 끄기(기본) / 전화처럼 받기 / 조건에 맞으면 자동 연결 | 주행 중에도 쓸 수 있어야 한다. 조건은 운전 프로필로 건다 | 자동 연결은 양쪽 동의를 지킨다. 둘 다 자동이면 바로 연결하고, 한쪽만 자동이면 상대에게 전화형 요청을 보낸다 |
| 운전 프로필을 점수(0~100)로 공개한다. 60점 이상만 상대에게 보이고, 취향은 점수 없는 배지로 보인다 | 운전 스타일로 고르려면 비교할 수 있는 값이 필요하다. 낮은 점수를 드러내지 않아야 한다 | 원시 신호는 차 밖으로 나가지 않는다. 속도를 칭찬하지 않는다 |
| 내 프로필의 각 항목에서 근거 상세(점수, 단계, 주행별 차트, 최근 주행)를 볼 수 있다. 상대는 확정 점수만 본다 | 내 점수가 어떻게 나왔는지 납득할 수 있어야 한다 | 주차 중에만 볼 수 있다 |
| 주행 데이터는 차량 신호로 실시간으로 쌓인다. 공개 전까지 '쌓이는 중' 화면을 보여 준다 | 프로필을 만들 재료를 앱이 스스로 모아야 한다 | 유효 주행 3회부터 공개된다. 과거 주행 기록을 가져오는 API는 확인하지 못했다 |
| 애프터는 카카오톡·인스타그램 아이디 맞교환으로 바꾸고, 앱 안의 글 대화와 연결 중 글 인사는 없앤다 | 애프터 뒤의 대화는 사람들이 이미 쓰는 메신저에서 이어지는 것이 자연스럽다. 통화가 생겨 글 인사는 필요 없다 | 둘 다 수락하는 순간에만 양쪽 아이디가 함께 보인다. 거절·철회·만료·차단이면 아무것도 공유되지 않는다 |
| 스친 인연과 이어진 인연을 하나의 `인연` 목록으로 합친다. 하단 탭은 홈·인연·내 프로필 3개다 | 두 탭을 나눈 이유는 앱 안 대화함이었다. 대화를 없애면 나눌 이유가 없다 | 받은 애프터 요청은 배지로 맨 위에 보인다 |
| 프로필은 사람마다 하나다. 계정 선택을 없앤다 | 실제 사용자는 프로필 하나로 쓴다 | 서버는 설치마다 계정을 만든다 |
| 혼자 둘러보기의 가상 상대는 유지하고, 통화에서는 Pleos 내장 음성으로 말한다 | 심사위원이 혼자 앱을 볼 때 주변에 다른 사람이 없어도 전체 흐름을 겪을 수 있어야 한다 | 화면에 시연·가상 표시를 반복하지 않는다. 첫 모드 선택에서만 알린다 |
| 심사 기간에 공개 서버를 운영한다 | 서버가 없으면 실제 사용을 시험할 수 없어 반쪽짜리다 | 운영 서버는 터널 뒤에서만 열리고, 사용자별 요청 제한과 공간 정원을 둔다 |
| UI를 전면 개편한다: 장면 배경, 큰 모찌 캐릭터, 한 화면 한 메시지, 차분한 하단 탭 3개 | 다른 팀의 차량 앱과 비교했을 때 분위기와 완성도가 부족했다 | 검정·빨강·흰색과 말랑한 입체감, 붉은 실은 유지한다 |

## 알려진 한계

- 점수는 차 안의 앱이 계산하므로 변조된 앱이 높은 점수를 꾸밀 수 있습니다. 자동 연결 조건도 이 점수를 믿습니다. 공개 운영 전에는 서명된 차량 신호로 검증해야 합니다.
