# 가상 상대 음성 클립

혼자 둘러보기(SOLO)와 서버 모드의 가상 상대(DEMO_PEER)가 통화에서 말하는 세 문장은 미리 만들어 앱에 넣은 음성 클립으로 재생합니다. 이 프로젝트를 위해 음성 합성 서비스로 만들었습니다.

## 만든 방법

| 항목 | 값 |
|---|---|
| 서비스 | ElevenLabs Text to Speech API |
| 모델 | `eleven_v3` |
| 목소리 | 보이스 라이브러리의 `Jjeong - Warm, Calm and Measured` (`DMkRitQrfpiddSQT5adl`), 다섯 상대 모두 같은 목소리 |
| 만든 날 | 2026-11-13 |
| 이용 조건 | 팀의 유료 구독으로 만들었습니다 |
| 후처리 | 앞뒤 무음 정리, 음량 정규화(약 −16 LUFS), mono 44.1 kHz 64 kbps MP3, 메타데이터 없음 |
| 위치 | `data/voice/src/main/res/raw/demo_voice_<상대>_<순서>.mp3` (15개, 약 284 KB) |

서비스에 보낸 것은 아래의 고정된 공개 프로필 문장뿐입니다. 사용자 정보, 차량 신호, 위치, 연락처는 보내지 않았습니다. 앱은 실행 중에 서비스를 부르지 않고, 키도 앱과 저장소에 없습니다.

## 문장

| 파일 | 상대 | 문장 |
|---|---|---|
| `demo_voice_star_1..3` | 별보는밤 | 안녕하세요, 별보는밤이에요. / 밤 풍경을 사진에 담는 걸 좋아해요. / 사진에 남기고 싶은 순간이 있나요? |
| `demo_voice_jazz_1..3` | 재즈한잔 | 안녕하세요, 재즈한잔이에요. / 재즈를 들으면 마음이 편안해져요. / 요즘 자주 듣는 곡이 있나요? |
| `demo_voice_slow_1..3` | 느린오후 | 안녕하세요, 느린오후예요. / 잔잔한 음악과 커피를 좋아해요. / 어떤 커피를 즐겨 마시나요? |
| `demo_voice_sea_1..3` | 바다보러가요 | 안녕하세요, 바다보러가요라고 해요. / 여행 이야기를 듣는 게 좋아요. / 서핑을 해 본 적이 있나요? |
| `demo_voice_forest_1..3` | 숲길산책 | 안녕하세요, 숲길산책이에요. / 캠핑하며 쉬는 시간을 좋아해요. / 캠핑할 때 꼭 챙기는 게 있나요? |

문장의 원본은 `data:voice`의 `DemoCallScripts`입니다. 문장을 바꾸면 클립도 다시 만들어야 합니다. `DemoCallClipsTest`는 모든 문장에 서로 다른 클립이 있는지 확인합니다.

## 다시 만들기

```sh
ELEVENLABS_API_KEY=... python3 scripts/demo_voice.py
```

- curl과 ffmpeg가 필요합니다.
- 키는 환경변수에서만 읽고 출력하거나 파일에 쓰지 않습니다. 키를 저장소에 커밋하지 마세요.
- 받은 원본은 `build/demo-voice-cache/`에 캐시되어 다시 받지 않습니다. 새로 받으려면 그 폴더를 지우세요.
- 스크립트의 문장 표와 `DemoCallScripts`의 문장이 같아야 합니다.

## 앱에서의 동작

- 클립은 통화 오디오와 같은 VOICE_COMMUNICATION 용도로 재생하고, 포커스 상실·집 보호·연결 종료 때 바로 멈춥니다.
- 클립을 재생하지 못한 문장은 Pleos TextToSpeech의 ON_DEVICE 음성이 대신 말합니다.
- 자동 연결 안내(`별보는밤님과 연결됐어요`)는 이름이 바뀌므로 Pleos 음성으로 말합니다.
