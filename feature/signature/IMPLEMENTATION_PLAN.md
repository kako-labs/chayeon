# 시그니처 화면 구현 계획

## 시그니처 탄생과 시연 경로 보정

- [x] `DemoConsole`의 세 시나리오를 각각 세 번 재생하고 진행 상태를 보여줘요. 마지막 요약은 읽지 않은 상태로 유지하고 주차 상태에서 이동해요.
- [x] `TripRecapScreen`에 1200ms 매듭 연출과 칭호·특성 순서를 넣고, 공개 범위와 내 시그니처로 연결해요. 애니메이션 끄기와 주행 잠금을 검사해요.
- [x] 내 시그니처의 획득 특성 위계를 높이고 내 프로필·특성 상세·공개 범위·콘솔의 잘림과 문구를 고쳐요.
- [x] `AppEvents`의 초기 신호를 기준값으로 처리하고 앱 배너를 레이아웃을 밀지 않는 크롬 영역에 겹쳐요.
- [x] 허용된 차량 저장소에 첫 시그니처 플래그를 저장하고 재시작·주행 제외 테스트를 추가해요. 공개 전의 첫 획득도 저장해요.
- [x] 설치한 debug APK에서 기어 전환을 측정하고 필요하면 `AutomotiveBackend`의 정책 수신 지연을 줄여요.
- [x] 기능·앱 기준 이미지를 기록하고 직접 읽은 뒤 지정된 최종 검증 명령과 에뮬레이터 캡처를 남겨요. 커밋하지 않아요.

목표: 내 프로필·내 시그니처·특성 상세·공개 범위·주행 후 요약을 실제 저장소 계약에 연결해요.

- [x] 화면별 불변 상태와 ViewModel을 구현해요. 현재 정책 재검사, 중복 방지, 같은 명령 재시도와 개인정보 숨김을 검증해요.
- [x] RedSettings·RedHome·RedCandidate·RedStyle의 PNG와 인라인 스타일을 기준으로 공용 UI 토큰·표면·매듭을 조립해요. 넓은 창은 두 열, 좁은 창은 스크롤하는 한 열이에요.
- [x] 공개 미리보기와 게시 본문은 같은 공개 투영을 사용해요. 특성 변경·주행 제외 후에는 게시 내용도 갱신해요.
- [x] 고정된 navigation 계약의 본문을 교체해요. 화면 밖 이동은 기존 SignatureExit를 사용해요.
- [x] 모든 화면의 주요 상태를 캡처하고 기준 시안과 비교해요. 상호작용·실패·주행 정책 변화 테스트를 추가해요.
- [x] 모듈 단위 테스트, Roborazzi 검증, lint, verifyArchitecture를 실행하고 자체 반박 검토를 해요.

이번 보정 범위는 feature/signature, app의 main·test, 명시적으로 허용된 data/vehicle 저장소·코덱·테스트예요. 공용 계약·빌드 파일은 유지하고 커밋하지 않아요. 공용 엔진의 칭호·매듭·특성 문구를 사용해요.
