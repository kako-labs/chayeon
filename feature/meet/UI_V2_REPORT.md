# Meet UI v2 적용 보고

`feature/meet`의 화면 조립과 모듈 내 내비게이션·테스트만 변경했어요. ViewModel, 저장소, 공용 계약, 의존성은 변경하지 않았고 커밋하지 않았어요.

## 화면과 시안

홈에서 직접 보내는 요청도 기존 `CandidateViewModel`의 재시도 키·재요청 대기·정책 검사를 사용해요. 전송 중에는 카드 넘김·상세 진입·새로 보기를 잠그고, 실패하면 동일 명령으로 재시도해요. 성공 이후에는 다음 요청을 위한 별도 화면 모델 키를 사용해요. 모든 기존 ViewModel 소스는 그대로예요.

주차 통화 시간은 연결 시작 시각과 `ServerTimeAnchor`의 단조 시각 차로 계산해요. 기준 시각이 없으면 시간을 만들어 표시하지 않아요. 주행·UNKNOWN에는 타이머와 이야깃거리가 없어요. 서버 모드의 가상 상대·합성 주행 라벨은 유지하고 SOLO에는 반복 표시하지 않아요.

## 모듈 전용 조각

공용 승격을 검토할 수 있는 새 조각은 다음과 같아요.

- `MeetSceneSplit`: 왼쪽 모찌·오른쪽 본문과 고정 행동, 1100dp 미만에서는 스크롤 한 열이에요.
- `MeetProfilePanel`: 아바타·칭호·출처·공개 점수·궁합·관심사 패널이에요.
- `MeetSourceLabel`: 공용 출처 표시 정책을 따르는 작은 라벨이에요.
- `MeetRecommendation`: ID로 선택을 유지하며 한 사람씩 넘기는 홈 카드예요.
- `MeetCallDetails`, `MeetCallStatus`: 통화 하단 패널과 상태·시간 표시예요.
- `MeetVoiceControl`: 공용 목록에 없는 마이크·통화 종료 아이콘을 Canvas로 그린 150/180dp 통화 조작이에요. 색·간격·곡률·글자는 공용 토큰을 사용해요.
- `meetScenePadding`: 공용 56/44/40dp 토큰을 조립한 화면 여백이에요.

새 리소스·라이브러리·전역 상태는 추가하지 않았어요.

새 문구는 `내 칭호`, `다음 사람 보기`, 홈의 `수락하면 바로 통화가 연결돼요`, 후보 상세의 `오늘의 인연`이에요. 요청 화면의 `함께하면 잘 맞는 점` 제목은 기존 후보 상세 문구를 재사용해요. `집 근처에서는 쉬고 있어요`와 거리 이탈 종료 제목에는 시안과 같은 줄바꿈을 추가했어요. 종료의 `끝난 시각`·`끝난 이유` 별도 타일은 제거하고 기존 종료 사유 제목·설명은 모두 유지했어요. 시그니처가 없는 후보의 `공개한 주행 특성이 생기면 여기에 보여요` 보조 문장은 생략하며 `시그니처를 만드는 중이에요`는 유지해요.

## 검증

기준 이미지 **126개**(기존 120개 재기록 + 신규 6개)를 기록했어요. 신규는 집 보호·발견 꺼짐·실패의 좁은 창, 좁은 홈의 행동 영역, 주차 통화 시간, 서버 요청이에요. 기존 파일을 삭제하지 않았고 모든 이미지의 상태·배치를 확인했어요. 주요 7개 화면은 원본 시안과 나란히 비교했어요.

최종 기록·검증 실행 모두 성공했어요. Roborazzi 검증을 포함한 **202개 테스트가 통과**했고 실패·오류·건너뜀은 모두 0개예요. Kotlin 컴파일과 `lintDebug`도 통과했어요.

| MeetMotionTest | 4 |
| MeetInteractionTest | 21 |
| MeetNavigationTest | 8 |

```sh
./gradlew :feature:meet:testDebugUnitTest -Proborazzi.test.record=true :feature:meet:lintDebug
./gradlew :feature:meet:testDebugUnitTest -Proborazzi.test.verify=true :feature:meet:lintDebug
```

명령은 `scripts/dev.py`의 기존 `execution_environment(android=True)`로 JDK 17과 SDK 환경을 지정해 실행해요. 파일이나 빌드 설정에 로컬 경로를 추가하지 않았어요. 최초 환경 지정 없는 Gradle 실행은 Java 버전 미설정으로 시작하지 못했고, 이후 환경을 지정해 Kotlin 컴파일을 통과했어요.

새 조작 검사는 한 명씩 넘기기·후보 제거 후 선택 복구·상세 이동·홈 직접 요청·전송 중 카드 잠금·동일 명령 재시도를 확인해요. 공용 v2 정적 에셋에 맞춰 기존 통화·종료 모션 검사를 정지 검사로 바꿨어요. 정책 전환 검사는 주행 화면의 의미 트리가 적용된 뒤 픽셀을 비교하도록 수정했어요. 기존 50ms 대기에서는 이전 주차 프레임이 캡처되는 것을 두 실제 이미지로 확인했어요.

## 시안과의 차이·통합 사항

- 애프터 버튼은 기존 `MeetExit.OpenEncounter(encounterId)`를 호출해 해당 인연 상세로 이동해요. 애프터 작성 화면으로 직접 여는 새 공용 출구는 추가하지 않았어요. 컨트롤러가 `app`·인연 트랙과 직접 진입을 연결해야 해요.
- 홈의 `새로 보기`, 상세·요청의 차단·신고, 마이크 안내, 오류·출처 라벨은 기존 행동과 정책 때문에 시안보다 추가 공간을 사용해요. 전체 특성이 많은 후보는 넓은 창에서도 스크롤해요. 좁은 홈의 행동도 스크롤로 접근해요.
- 타이머가 없는 기준 이미지는 서버 시간 기준점이 전달되지 않은 상태예요. `connected_elapsed.png`가 실제 시간 표시 변형이에요. 예시 인원·점수·상대·관심사 대신 실제 공개 데이터와 테스트 fixture를 사용해요.
- 공용 WebP·Brush·버튼·아바타 접시를 사용해 HTML의 blur, 장면 크롭·좌우 구도, 외곽 광택과 완전히 동일하지는 않아요. 음소거·끊기 전용 아이콘만 모듈 내부 Canvas로 그렸어요. 공용 CallHero·작별 모찌는 정적이에요.
- 기능 단독 스크린샷의 `previewChrome`에는 앱 브랜드가 없어요. 앱 상단 브랜드·탭 배지·전역 배너 배치는 `app` 소유이며 이 트랙에서는 변경하지 않았어요.
- Pleos 실기기·에뮬레이터 E2E, 실제 음성·서버 통합, GPU 성능·야간 가독성은 이번 작업에서 검증하지 않았어요. 전체 `dev.py verify`는 brief대로 실행하지 않았어요.
