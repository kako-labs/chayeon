# w12b-profile UI v2 구현 보고

`feature/history`, `feature/signature`의 표시 계층과 해당 테스트·기준 이미지만 변경했어요. ViewModel, 저장소, 모델, 내비게이션 계약, 의존성은 변경하지 않았고 커밋하지 않았어요.

## 모듈 내부 구성요소

공용 승격 후보는 아래와 같아요. 모두 기존 core:ui 토큰·에셋을 사용해요.

- history: `HistoryButton`(기존 버튼 인자를 v2 버튼으로 연결), `ProfileSteps`, `HistorySceneHero`, `ProfileAvatarPicker`(가로 스크롤·선택 의미 유지), `SharedContactCard`(가용 너비에 따라 QR 옆/아래 배치).
- signature: `SignatureButton`, `DrivingModeCard`, `ProfileTraitRow`, `ScoreStageLadder`. 기존 `CountTile`도 개별 글래스 타일로 바꿨어요.
- `HistoryFrame`은 장면·제목 표시 옵션을, `SignatureFrame`은 장면·열 비율 옵션을 받아요. 공개 기능 API 변경은 없어요.
- 내 프로필의 새 `설정` 버튼은 기존 설정 행으로 스크롤해요. `주행 중 연결` 진입은 그 설정 행에 있어요.

## 변경한 사용자 문구

줄바꿈·배치 변경만 있는 문구와 그대로 유지한 버튼 이름은 제외했어요. 아래 범위 밖의 동일 문구는 기존대로예요.

| 범위 | 이전 | 이후 |
|---|---|---|
| 참여 준비 단계 | 시작 · 프로필 · 공개 범위 (3단계) | 프로필 · 공개 범위 (2단계) |
| 프로필 왼쪽 소개 | 상대에게 이렇게 보여요 | 운전하는 나를 소개해요 |
| 프로필 소개 설명 | 직접 고른 공개 시그니처만 함께 보여요 | 닉네임과 캐릭터로 만나요. 연락처는 애프터에서 직접 골라요. |
| 프로필 아바타 선택 제목 | 가상 아바타 | 캐릭터 |
| 프로필 연락처 제목 | 애프터 아이디 · 선택 | 애프터 때 건넬 아이디 · 선택 |
| 동의 설명 | 공개를 고른 특성과 단계만 서버와 상대에게 보여요. 수치와 순위는 공유하지 않아요. | 공개를 고른 특성과 점수만 서버와 상대에게 보여요. 주행 기록과 순위는 공유하지 않아요. |
| 인연 부제 | 스친 순간부터 이어진 마음까지 | 길 위에서 통화한 사람들이 모여요 |
| 인연 목록의 받은 요청 배지 | 애프터가 왔어요 | 애프터 요청이 왔어요 |
| 인연 목록의 연결 배지 | ♥ 이어진 인연 | 이어졌어요 (하트는 아이콘) |
| 이어진 관계 제목 | ♥ 마음이 이어졌어요 | {상대 이름}님과 이어졌어요 |
| 이어진 관계 설명 | 서로 고른 아이디를 나눴어요 | 서로 애프터를 수락했어요 / 서로 고른 아이디로 이야기를 이어가세요 |
| 상대 Instagram 라벨 | 인스타그램 | {상대 이름}님의 인스타그램 |
| 근거 기간 표시 | 최근 30일 · {기간} | 기간 / 최근 30일 타일과 별도 {기간} |

추가한 문구:

- 관계 카드: `휴대폰으로 QR을 찍으면 바로 열려요`, `아이디는 둘 다 수락한 순간에만 오가요 · 주행 중에는 숨겨요`.
- 내 프로필: `내 칭호`, `최근 30일 · 주행 {실제 반영 횟수}회로 만들었어요`, `설정`.
- 프로필 만들기: `공개까지`. 기존 3회 안내·공개를 직접 고른다는 안내는 진행 패널에 유지했어요.
- 연결 설정: `달리는 동안 새 사람과 어떻게 이어질지 골라요.`, `이어지면 차 안 음성이 알려 줘요`, `상대의 닉네임과 연결 사실만 알려 줘요. 통화 끊기 한 번으로 끝낼 수 있어요.`

`저장하고 다음`, `수락하고 이어가기`, `애프터 신청 보내기`, `관계 끝내기`, 기존 설정·안전 행동 버튼 이름은 유지했어요. 인연 행에서는 `답하기` 또는 `애프터 신청`이 있으면 별도의 `인연 보기` 버튼을 중복 배치하지 않지만 행을 누르는 상세 진입은 유지했어요.

## 타깃과의 차이 및 통합 확인점

- 실제 항목 수를 유지했어요. 14개 관심사, 6개 아바타, 두 연락처 입력, 12개 특성, 전체 자동 연결 조건 때문에 목업보다 스크롤이 길어요. 아바타는 가로 스크롤이며 마지막 항목도 직접 선택할 수 있어요.
- 20sp 최소 글자와 76dp 터치 대상을 유지해 목업의 작은 행·칩보다 커요. 제한 상태의 버튼은 공용 v2 버튼의 96dp 하한을 사용해요.
- 근거 점수는 공용 최대 헤드라인 84sp를 사용해 목업의 148px보다 작아요. QR은 공용 256dp를 유지해 목업의 220px보다 커요. 픽셀 단위 일치는 아니에요.
- 예시 숫자·칭호·관심사·연락처는 복제하지 않았어요. 매듭은 실제 시드 기반 SignatureKnot을 유지하며 목업의 단일 실 이미지와 달라요.
- 공용 장면의 스크림과 입력·동의·확인 컴포넌트는 기반 구현을 사용해요. 일부 확인창·상태 카드는 공용 기존 모양을 유지해요.
- 온보딩 저장 버튼은 넓은 창에서 오른쪽 폼 너비, 좁은 창에서는 전체 너비로 고정했어요. 폼과 스크롤을 분리해 목업처럼 패널 안에 완전히 붙어 있지는 않아요.
- app 크롬을 수정하지 않아 제목·뒤로·상태 영역의 높이는 목업과 달라요. 모듈 테스트는 previewChrome을 사용하므로 병합 후 실제 앱 크롬과 함께 확인해야 해요.
- 플랫폼 마이크·위치 권한 창, 실제 차량 신호 전환, 물리 화면의 가독성은 이번 실행에서 검증하지 않았어요.
