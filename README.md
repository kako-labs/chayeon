# 차연

길 위에서 시작되는 인연. 주변 참여자와 서로 동의해 연결하고, 멀어지면 끝나며, 서로 다시 원할 때만 이어지는 차량 앱입니다.

HMG 앱 공모전의 2순위 작품(가칭)입니다. 1순위 작품은 [motion-care](https://github.com/kako-labs/motion-care)입니다.

## 현재 상태

기획과 디자인 시안 단계입니다. 앱 코드는 아직 없습니다.
