# 차연

길 위에서 시작되는 인연.

차연은 **주행 습관과 차량 관리가 프로필이 되는** 차량용 인연 앱입니다. 사진과 글로 꾸민 자기소개 대신, 옆 사람이 놀라지 않게 미리 멈추는 습관이나 떠나기 전에 차를 살피는 습관으로 나를 보여 줍니다. 근처에 있는 사람과 서로 원할 때만 잠시 이어지고, 다시 원할 때만 계속됩니다.

Pleos Connect(Android Automotive)용 앱과 서버를 담은 모노레포입니다. HMG 앱 공모전 출품작이며 이름은 가칭입니다.

## 드라이브 시그니처

차 안에서 주행과 차량 관리 신호를 요약해 상대에게 매력으로 읽히는 프로필을 만듭니다.

| 구성 | 내용 |
|---|---|
| 특성 12가지 | 주행 스타일 7가지와 차량 관리 5가지. 예: `여유로운 제동`, `깜빡이 매너`, `미리 채우는 습관`, `실내 공기 챙김` |
| 칭호 | 공개한 특성으로 만드는 한 줄 소개. 예: `떠나기 전에 살피는 드라이버` |
| 시그니처 매듭 | 습관에 따라 모양이 달라지는 붉은 3D 매듭. 궁합 화면에서는 두 사람의 매듭이 빨강과 진주색으로 엮입니다 |
| 드라이브 궁합 | 점수 없는 문장. 예: `둘 다 출발 전에 안전부터 챙겨요` |
| 주행 후 요약 | 주차하면 이번 주행의 변화를 나에게 먼저 보여 줍니다. 다른 사람이 운전했다면 뺄 수 있습니다 |
| 공개 범위 | 특성마다 공개를 고르고, 상대에게 보이는 모습을 미리 봅니다 |

원시 신호는 메모리에서만 처리하고 저장하거나 전송하지 않습니다. 상대와 서버에는 내가 공개한 특성과 단계만 갑니다. 수치, 순위, 낮은 평가는 상대에게 보이지 않고, 속도를 칭찬하지 않으며, 주행 중에는 결과를 보여 주지 않습니다. 자세한 원칙은 [드라이브 시그니처 명세](docs/product/drive-signature.md)에 있습니다.

## 집 보호 구역

집을 정하면 반경(300m, 500m, 1km) 안에서는 발견을 쉽니다. 이어져 있던 상대에게는 멀어져서 끝난 것과 똑같이 보입니다.

- 집 좌표와 반경은 차 안에만 저장하고 서버로 보내지 않습니다. 저장할 때 중심을 반경의 최대 25%만큼 무작위로 옮깁니다.
- 반경에 들어오면 바로 쉬고, 벗어난 뒤에는 30~90초를 무작위로 더 확인하고 돌아옵니다. 위치를 확인할 수 없으면 쉬는 쪽으로 동작합니다.
- 서버의 발견 상태는 앱이 20초마다 갱신하고, 갱신이 60초 동안 없으면 만료됩니다. 그래서 집 도착, 앱 종료, 통신 단절이 상대에게 같은 모습으로 보입니다.

## 3분 둘러보기

차와 서버 없이 에뮬레이터만으로 제품 전체를 볼 수 있습니다. `혼자 둘러보기`는 첫 선택에서 가상 상대임을 안내하며, 데이터 출처는 내 시그니처 근거에서 확인할 수 있습니다.

1. **첫 실행:** `혼자 둘러보기(가상 상대)`를 고르고 `이 계정으로 시작`을 누릅니다.
2. **준비:** `저장하고 다음`을 누르고 성인 확인·차량 데이터·위치·프로필 공개 네 항목에 동의합니다. 권한 창에서 허용한 뒤 `선택한 설정으로 시작`을 누릅니다. 마이크 행은 선택이며 SOLO는 마이크 없이 진행합니다.
3. **시그니처 탄생:** 홈에서 `발견 켜기` → `시그니처 만들러 가기` → `다음 움직임을 알려 주는 사람`을 누릅니다. 약 30초 뒤 매듭이 그려지며 칭호와 특성이 나타납니다. 다른 성격을 고르면 다른 칭호와 매듭이 나옵니다.
4. **공개와 근거:** `상대에게 어떻게 보일지 고르기` → `시그니처 공개`를 누릅니다. `내 프로필` → `내 시그니처 보기` → `깜빡이 매너`에서 `시그니처 근거: 합성 주행`을 확인하고, 뒤로 → `오늘의 인연`을 누릅니다.
5. **만남:** `별보는밤`의 `프로필 보기`에서 특성과 궁합을 보고 `연결 요청 보내기`를 누릅니다. Virtual Console에서 D로 바꾸고 상대 수락을 기다리면 `통화 중` 화면이 자동으로 열리고 `음소거`와 `통화 끊기`가 보여요. P로 돌아오면 통화 화면의 `이야깃거리`에서 공통 관심사·궁합·칭호를 보며 목소리로 이야기해요. 다른 시연용 가상 상대는 거절, 무응답, 잠시 멀어짐을 보여줍니다.
6. **주행 중 통화:** Virtual Console에서 기어를 D로 바꾸면 통화가 이어지고 `음소거`와 `통화 끊기`만 남아요. `음소거` → `음소거 해제`를 누릅니다. N 정차와 D 주행에서도 두 조작만 허용하고, P로 돌아오면 `이야깃거리`를 다시 볼 수 있어요.
7. **이별과 애프터:** 상단 `시연 제어` 아이콘 → `서로 멀어져요` → 뒤로 가기를 누르면 확인 상태를 거쳐 연결이 끝납니다. `기록 보기` → `애프터 신청` → `애프터 신청 보내기` → `이어진 인연 보기` → `안녕하세요`로 다시 인사를 주고받습니다.
8. **집 보호:** `내 프로필`의 `집 보호 구역`에서 `집 보호 시작하기`를 누르면 하단 오브가 `쉬는 중`으로 바뀌고 후보가 사라집니다. `오늘의 인연`으로 돌아와 `시연 제어` 아이콘 → `집에서 멀어지기` → `오늘의 인연`을 누르면 잠시 뒤 상대가 돌아옵니다. `별보는밤`의 `프로필 보기` → `연결 요청 보내기`로 연결한 뒤 `시연 제어` 아이콘 → `집 근처로 오기` → 뒤로 가기를 누르면 `서로 멀어져서 통화가 끝났어요` 화면이 나옵니다. `오늘의 인연으로` → `시연 제어` 아이콘 → `집에서 멀어지기` → `오늘의 인연`으로 돌아옵니다.
9. **실제 신호:** Virtual Console로 3분 이상 주행하고 주차하면 주행 후 요약이 나옵니다.

## 실행 방법

### APK 설치

Pleos 에뮬레이터의 앱 사용자는 10입니다. 시리얼은 `adb devices`로 확인합니다.

```sh
adb -s <시리얼> install --user 10 apk/chayeon-release.apk
adb -s <시리얼> shell am start --user 10 -n dev.chayeon/.MainActivity
```

### 소스에서 빌드

JDK 17과 Android SDK 35가 필요합니다. Vehicle SDK는 빌드할 때 Pleos 저장소에서 받습니다.

```sh
python3 scripts/dev.py doctor     # 환경 확인
python3 scripts/dev.py setup-sdk  # 필요한 SDK 설치
python3 scripts/dev.py emulator   # Pleos 에뮬레이터 실행
python3 scripts/dev.py verify     # 구조 검사, 테스트, 스크린샷 비교, lint, 빌드
python3 scripts/dev.py release    # apk/chayeon-release.apk 생성
```

`release`는 시연 제어를 켜고 서버 주소 없이 빌드합니다. 서명에는 빌드할 때 만드는 로컬 일회용 키를 쓰며, 이 키는 Git에 넣지 않습니다.

`e2e`와 `drive`는 AVD 이름이 `Pleos_Connect_v2_0`인 에뮬레이터 한 대만 자동으로 고릅니다. `e2e`는 그 에뮬레이터의 앱을 지우고 다시 설치하므로, 여러 대를 띄웠다면 `CHAYEON_EMULATOR_SERIAL`로 대상을 지정합니다.

### 두 대로 연결 (선택)

서버를 켜고 서버 주소를 넣어 빌드하면 첫 화면에 `두 대로 연결(서버)`이 나타납니다. 같은 방 코드에 서로 다른 테스트 계정으로 들어가면 실제 통신으로 이어집니다.

```sh
python3 scripts/dev.py server
./gradlew :app:assembleDebug -Pchayeon.serverUrl=http://10.0.2.2:8080
```

서버만 빌드할 때는 Android SDK가 필요 없습니다. `server/Dockerfile`도 있으나 이미지 실행은 확인하지 않았습니다.

```sh
./gradlew -Pchayeon.serverOnly=true :server:build
```

### 에뮬레이터 주행

```sh
python3 scripts/dev.py drive care --duration-seconds 210
```

시나리오는 `gentle`, `early-brake`, `signal-manners`, `care`, `unsupported`입니다.

## 테스트 환경

| 항목 | 값 |
|---|---|
| 에뮬레이터 | Pleos Connect v2.1.0, API 34, AVD `Pleos_Connect_v2_0` |
| 앱 창 | 1682×1210dp, 160dpi, 사용자 ID 10 |
| 차량 입력 | Virtual Console |
| 호스트 | macOS arm64 |
| 도구 | JDK 17, Gradle 8.12, Android Gradle Plugin 8.10.1, Kotlin 2.1.20 |
| SDK | compileSdk·targetSdk 35, minSdk 28, Vehicle SDK 2.3.2 |

실차와 App Market 승인 환경에서는 시험하지 않았습니다.

## APK 위치

`python3 scripts/dev.py release`를 실행하면 `apk/chayeon-release.apk`가 생깁니다. 제출할 때는 공모전 형식인 `팀명_앱이름_release.apk`로 이름을 바꿉니다.

## 한계

- 시그니처는 차량 안 클라이언트에서 계산하므로 변조를 완전히 막지 못합니다. 공개 서비스로 가려면 서명된 차량 신호나 서버 검증이 필요합니다.
- 상대와의 근접 판단은 합성 값입니다. 실제 위치 기반 근접은 구현 경로만 있고 시연하지 않습니다. 기기 위치는 집 보호 구역에만 씁니다.
- 앱이 강제 종료되거나 차 전원이 꺼지면 서버 만료까지 최대 60초 동안 더 발견될 수 있습니다. 늦게 도착한 갱신이 이탈 뒤에 처리되면 그만큼 다시 노출될 수 있습니다.
- 서버 운영자는 이탈 명령이 도착한 사실을 볼 수 있고, 이번 빌드에는 실제 위치 기반 이탈이 없으므로 집 보호 때문이라고 추측할 수 있습니다. 좌표와 반경은 서버에 가지 않으며, 상대에게는 이 차이가 보이지 않습니다.
- 집을 정한 사용자가 터널이나 지하 주차장에서 위치를 잃으면 발견을 쉬고, 연결 중이었다면 끝날 수 있습니다.
- 저장된 집 중심은 앱 전용 저장소에 암호화 없이 있습니다. 며칠에 걸친 부재 패턴으로 집을 짐작하는 추론은 막지 못합니다.
- 이 에뮬레이터 이미지는 타이어와 소모품 신호를 지원하지 않습니다. 실제 신호 주행에서 이 특성들은 `이 차량에서 제공되지 않아요`로 표시됩니다.
- 임계값은 제품 기준이며 안전이나 의학 기준이 아닙니다. 실차 센서 노이즈에 맞춘 보정은 하지 않았습니다.
- 공개 서버를 운영하지 않습니다. 시연용 로그인과 연령 자기 확인은 실제 인증이 아닙니다.
- 사용자 수요와 재방문은 측정하지 않았습니다.

```txt
app/             앱 조립, 내비게이션, 시연 제어, 알림
core/model       도메인 모델, Repository 인터페이스, API 계약
```

## 통화 안내

수락된 일시 연결 동안만 통화해요. 온보딩의 마이크 선택은 가입 조건이 아니며 거부하거나 입력 장치가 없으면 수신만 유지해요. 데모 상대는 SOLO와 서버 모드 모두 마이크와 음성 WebSocket을 열지 않고 Pleos 기기 내 음성으로 준비된 세 문장을 들려줘요. 문장 시작 시각 기준 약 20초 간격으로 재생해요. SOLO에서는 네트워크를 사용하지 않아요. `주행 중에도 새 요청 받기`는 기본 OFF이고 내 프로필에서 주차 중 바꿀 수 있어요. 실제 두 계정의 PCM 통화는 방향당 약 256 kbps이며 Opus 압축은 후속 계획이에요. 데모 음성은 Pleos TextToSpeech 3.3.1의 ON_DEVICE 모드와 일반 권한 `pleos.car.permission.TTS_SERVICE`를 사용해요. 차연의 기기 발화·지연은 아직 검증하지 않았어요. 팀의 이전 앱에서 측정한 초기 약 4.5초·이후 약 3초 지연은 차연의 측정값이 아니에요.
