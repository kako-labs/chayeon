# 이야기 영상 (ChayeonStory)

한 운전자의 하루를 순서대로 따라가는 3분 9.3초 영상입니다. 주차한 뒤 시그니처가 생기고, 근처의 사람을 만나고, 다시 길에 올랐다가, 멀어지고, 집에 돌아오기까지입니다.

- **결과:** `~/Documents_LOCAL/chayeon-video/chayeon-story.mp4` (1920x1080, 30fps, 소리 없음)와 720p 미리보기 `chayeon-story-preview.mp4`. 영상과 녹화본은 Git에 넣지 않습니다.

## 방향을 정한 근거

같은 상황 설명만 준 AI 페르소나 셋에게 따로 의견을 받았습니다(2026-11-13). 실제 전문가가 아닙니다.
- 페르소나: 시연 영상 감독, 차량 HMI·UX 전문가, 공모전 심사위원
- 상황 설명: 앱 기능, 에뮬레이터·가상 상대 촬영 조건, 팀 영상 규칙(모션케어 영상에서 정한 것)

**세 의견이 같았던 것**
- 한 사람의 시간순을 따라갑니다: 주차 → 시그니처 → 발견 → 수락·인사 → 주행 잠금 → 멀어짐·기록 → 애프터 → 집. 기능을 나열하지 않습니다.
- 주행 잠금은 왼쪽 계기(기어·속도)와 앱 잠금이 한 화면에 1배속으로 함께 보여야 합니다. D 정차에서도 잠기는 장면을 넣습니다.
- 시그니처 생성 대기와 3분 이상의 주행은 잘라서 "30초 뒤", "3분 뒤"로 표시합니다.
- 온보딩, 설정, 여러 상대 둘러보기, 문장 입력은 넣지 않습니다.
- 피할 것: 기능 몽타주, 원인과 결과를 잘라 붙이기, 주행 중 조작처럼 보이는 장면, 수치·순위가 보이는 컷.

- 영상은 실제 서비스처럼 보입니다. 화면에 "시연용", "가상", "합성" 같은 말을 반복하지 않고, 끝에 녹화 방식을 한 번만 밝힙니다.

**화면 규칙** (모션케어 영상과 같음)
- **화면:** Pleos 화면 2560x1440을 1568x882로 늘 같은 자리에 둡니다. 왼쪽 계기(속도·기어)를 자르지 않습니다. 아래 띠에 장 이름과 자막 한 문장을 둡니다.
- **강조:** 필요하면 주변을 조금 어둡게 하고 얇은 테두리를 그립니다. 빛 번짐, 깜빡임, 확대는 쓰지 않습니다.
- **누른 위치:** 녹화 스크립트가 남긴 탭 위치·시각으로 옅은 원을 그립니다.
- **속도:** 모든 장면 1배속. 건너뛴 구간은 "30초 뒤", "3분 뒤", "서로 멀어진 뒤"처럼 띠에 표시합니다.
- **시연 제어:** 앱 위 작은 아이콘으로 여는 시연 제어 패널은 영상에 나오지 않게 그 구간을 자르고 표시합니다.


## 원안과 실제 제작의 차이

- 원안 표의 끝은 3:16으로 요청한 상한 3:15를 넘었습니다. 실제 앱의 전환·수락 시간을 포함하면서 장면 체류를 조정해 3:09.3으로 만들었습니다. 순서는 같습니다. 상대 프로필은 8초, 첫 시그니처는 8초 이상 보입니다.
- 발견은 약 17.9초, 애프터는 약 25.9초, 집은 약 21.3초입니다. 애프터 수락과 실제 탐색 시간을 보존했고 별도 대기 컷이나 배속을 넣지 않았습니다.
- 주행 후 요약은 하단 메뉴가 없는 전체 화면이므로, `뒤로`로 돌아온 뒤 `내 프로필`에 들어갑니다. 앱은 수정하지 않았습니다.
- 집으로 가는 구간은 Virtual Console D 상태 약 207초, 40km/h 유지 약 205초입니다. 180초 요건을 넘긴 뒤 P에서 실제 `주행 후 요약`을 확인했습니다. 원안의 210초와 약간 다릅니다.
- VideoToolbox 압축 세션이 실패해 녹화는 libx264를 사용했습니다. Chromium 실행은 호스트 권한 제한으로 차단됐습니다. Remotion 4.0.380 키트는 남겼으며, 최종 MP4는 같은 TypeScript 장면 표를 내보내 FFmpeg 동시성 4로 렌더했습니다. Remotion CSS 렌더와 픽셀 단위 동일성은 확인하지 못했습니다.

## 확인과 한계

- `pnpm run typecheck` 통과. Python 구문 검사와 Node 녹화기 구문 검사 통과.
- 완성본의 전체 1fps 프레임 시트 3장을 확인하고, 첫 시그니처·프로필·D 주행·D 정차·멀어짐 컷·요약·집을 원본 크기로 추가 확인했습니다.
- 첫 검수에서 멀어짐 컷 직후 패널의 전환 잔상이 보였습니다. 컷 시작을 1초 늦춰 제거했습니다.
- 시연 제어 패널과 시연용·가상·합성 문구는 마무리 고지 외에 최종 선택 구간에서 보이지 않음을 확인했습니다. 왼쪽 계기는 항상 포함하고 화면 비율은 유지합니다.
- 미리보기는 1280×720, 30fps, CRF 27, ultrafast입니다. 정적인 화면이 많아 slow에서는 약 2.3MB였고, 요청한 4~8MB 범위로 맞추었습니다.
- 집 보호 장면은 SOLO의 `집 보호 시작하기` 경로입니다. 실제 GPS로 집 경계 진입·이탈을 검증한 영상이 아닙니다. 실차 미확인입니다.
- 이 트랙은 앱을 바꾸지 않았고 브리프의 좁은 검증(타입 검사·영상 검수)을 실행했습니다. 앱 전체 `scripts/dev.py verify`는 실행하지 않았습니다.
